
# Ichgram/core

Ichgram/core is an application that is part of the microservice architecture of the ichgram system.
The purpose of this service is to handle the core logic for working with users, content, chats, and messages.



## Installation

### Prepare ichgram/core for instalation

```bash
  cp .env.example .env
```
* Fill all empty variables with your credentials

### Install ichgram/core with npm

```bash
  npm install
  npm run dev
```

### Install ichgram/core with docker

```bash
  docker-compose build
  docker-compose up -d
```
## Deployment

### To run ichgram/core project in production

```bash
  npm run build
  npm run prod
```
